A personal project documenting my journey solving the [Cryptopals Crypto Challenges](https://cryptopals.com/) in C.

## My Approach: No AI Assistance
I'm working through the Cryptopals Crypto Challenges in C, implementing everything from scratch.

No AI. No code completion assistants. No copying from Stack Overflow.

For example, my **AES** implementation was built by carefully studying **[NIST FIPS 197](https://csrc.nist.gov/publications/detail/fips/197/final)**. Only then I write code. If something doesn't work, I go back to the spec and/or debug with `gdb`/`valgrind`. The struggle is where the learning happens.
